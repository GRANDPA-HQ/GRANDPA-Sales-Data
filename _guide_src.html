매출 자동 추출 프로그램

쿠팡이츠 · 쿠팡포스 · 배민셀프서비스 통합 · 사용 설명서

1. 이 프로그램은 무엇인가요?

쿠팡이츠쿠팡포스배민 세 채널의 매출·주문 내역을 실행파일 하나로 순서대로 자동 추출해 CSV 파일로 저장해 주는 프로그램입니다. 원하면 Supabase 데이터베이스에도 자동으로 적재됩니다.

동작 방식
  • 실제 크롬 브라우저를 자동으로 구동해, 평소 사장님이 직접 조회하던 것과 똑같은 방식으로 데이터를 가져옵니다.
  • 채널별로 한 번만 로그인하면 세션이 저장되어, 다음부터는 자동 로그인 상태로 바로 조회됩니다.
  • 차단을 우회하는 것이 아니라, 본인 매장 데이터를 본인이 조회하는 것을 자동화한 것입니다.
  • 전체_매출추출.bat 하나만 실행하면 기간을 한 번 선택한 뒤 쿠팡이츠 → 쿠팡포스 → 배민 순서로 이어서 추출합니다.

2. 최초 준비 (처음 한 번만)

① Node.js 확인

이 PC에는 이미 Node.js가 설치되어 있습니다. (없는 다른 PC에서 쓰려면 nodejs.org 에서 설치)

② 첫 실행 & 채널별 로그인

1
전체_매출추출.bat 파일을 더블클릭합니다.
(처음에는 각 폴더에 필요한 구성요소를 자동 설치하므로 몇 분 걸릴 수 있습니다.)
2
기간 선택 창이 뜨면 원하는 기간을 고르고 [추출하기]를 누릅니다. (이 기간은 세 채널 모두에 동일하게 적용됩니다.)
3
[1/3] 쿠팡이츠 단계에서 크롬 창이 뜨면 직접 로그인합니다. 로그인 후 매출관리 페이지가 보이면 검은 명령창으로 돌아와 Enter를 누릅니다.
4
이어서 [2/3] 쿠팡포스, [3/3] 배민 단계에서도 같은 방식으로 크롬 창이 뜨면 그 채널 계정으로 로그인 → 명령창에서 Enter를 반복합니다.
각 채널의 로그인 정보는 채널별 폴더 안의 coupang_profile / coupos_profile / baemin_profile 폴더에 저장되어, 다음부터는 로그인 없이 바로 사용할 수 있습니다.

3. 평소 사용법

1
전체_매출추출.bat 더블클릭
2
기간 선택 창이 딱 한 번 뜹니다.
  • 달력에서 시작일 / 종료일을 직접 지정
  • 또는 빠른 버튼: 오늘 어제 최근 7일 최근 30일
3
[추출하기] 클릭 → [1/3] 쿠팡이츠 → [2/3] 쿠팡포스 → [3/3] 배민 순서로 자동 진행되며, 채널별로 진행 상황이 명령창에 표시됩니다.
4
세 채널 모두 끝나면 완료 메시지와 함께 세 개의 결과 폴더가 자동으로 열립니다.
선택하지 않으면? 창을 그냥 닫거나 [취소]를 누르면 자동으로 오늘 날짜 매출을 불러옵니다.
한 채널만 뽑고 싶다면? 각 폴더 안의 개별 실행파일을 써도 됩니다. (아래 "7. 폴더 구성" 참고)

4. 결과 파일

추출이 끝나면 채널별 output 폴더가 자동으로 열립니다.

채널폴더파일설명

5. Supabase 자동 적재 (선택)

메인 폴더의 .env 파일 하나에 SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY를 설정해 두면, 세 채널 모두 추출과 동시에 Supabase 데이터베이스에도 자동으로 저장됩니다.

  • .env는 메인 폴더에 하나만 두면 됩니다. 쿠팡포스·배민 하위 폴더는 자기 폴더에 .env가 없으면 자동으로 상위(메인) 폴더의 .env를 찾아 사용합니다.
  • .env가 없어도 프로그램은 정상 동작하며, 이 경우 CSV 파일만 저장되고 DB 적재는 건너뜁니다 (오류 아님).

6. 매일 자동 실행 (선택)

정해진 시간에 자동으로 어제 매출을 저장하려면 Windows 작업 스케줄러에 등록하세요.

  1. 시작 메뉴에서 작업 스케줄러 실행 → 기본 작업 만들기
  2. 트리거: 매일, 원하는 시간 (예: 오전 9시)
  3. 동작: 프로그램 시작 → 프로그램에 run_daily.bat 경로 지정
  4. 완료. 창 없이 조용히 실행되어 output 폴더에 저장됩니다.
run_daily.bat는 현재 쿠팡이츠 채널만 자동화합니다 (기간 선택 창 없이 조용히 실행되어야 하므로). 쿠팡포스·배민을 포함한 무인 자동 실행이 필요하면 별도로 요청해 주세요.
먼저 "2. 최초 준비"의 채널별 로그인을 반드시 끝내둬야 자동 실행이 정상 동작합니다.

8. 문제 해결

증상해결
특정 채널 단계에서 CSV가 안 생기고 403 등 오류 표시 해당 채널의 로그인 세션이 만료된 것입니다. 그 채널 폴더의 개별 실행파일 (예: 쿠팡포스_매출추출.bat)을 실행해 크롬 창에서 재로그인하면 됩니다.
기간 선택 창이 안 뜸 명령창을 닫고 전체_매출추출.bat을 다시 더블클릭하세요.
"Node.js가 설치되어 있지 않습니다" nodejs.org에서 Node.js 설치 후 다시 실행하세요.
"쿠팡포스/배민 폴더를 찾을 수 없습니다" coupang-pos-export-node, baemin-self-export-node 폴더가 전체_매출추출.bat과 같은 위치에 있는지 확인하세요.
다른 기간을 뽑고 싶음 기간 선택 창의 달력에서 시작일·종료일을 원하는 대로 지정하면 되고, 세 채널 모두 같은 기간으로 추출됩니다.
