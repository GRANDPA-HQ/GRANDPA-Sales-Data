쿠팡이츠 매출 자동 추출 프로그램

사용 설명서 · 매출관리 데이터를 CSV로 자동 저장

1. 이 프로그램은 무엇인가요?

쿠팡이츠 사장님 포털의 매출관리 화면에 있는 주문·매출 내역을 버튼 한 번으로 엑셀용 CSV 파일과 원본 JSON으로 저장해 주는 프로그램입니다.

동작 방식
  • 실제 크롬 브라우저를 자동으로 구동해, 평소 사장님이 직접 조회하던 것과 똑같은 방식으로 데이터를 가져옵니다.
  • 한 번 로그인하면 세션이 저장되어, 다음부터는 자동 로그인 상태로 바로 조회됩니다.
  • 차단을 우회하는 것이 아니라, 본인 매장 데이터를 본인이 조회하는 것을 자동화한 것입니다.

2. 최초 준비 (처음 한 번만)

① Node.js 확인

이 PC에는 이미 Node.js가 설치되어 있습니다. (없는 다른 PC에서 쓰려면 nodejs.org 에서 설치)

② 첫 실행 & 로그인

1
쿠팡이츠_매출추출.bat 파일을 더블클릭합니다.
(처음에는 필요한 구성요소를 자동 설치하므로 1~2분 걸릴 수 있습니다.)
2
크롬 창이 뜨고 로그인 화면이 나오면 직접 로그인합니다.
3
로그인 후 매출관리 페이지가 보이면, 검은색 명령창으로 돌아와 Enter를 누릅니다.
이때 로그인 정보가 coupang_profile 폴더에 저장되어, 다음부터는 로그인 없이 바로 사용할 수 있습니다.

3. 평소 사용법

1
쿠팡이츠_매출추출.bat 더블클릭
2
기간 선택 창이 뜹니다.
  • 달력에서 시작일 / 종료일을 직접 지정
  • 또는 빠른 버튼: 오늘 어제 최근 7일 최근 30일
3
[추출하기] 클릭 → 해당 기간 데이터가 저장됩니다.
선택하지 않으면? 창을 그냥 닫거나 [취소]를 누르면 자동으로 오늘 날짜 매출을 불러옵니다.

4. 결과 파일

추출이 끝나면 output 폴더가 자동으로 열립니다. 파일 두 개가 생성됩니다.

파일설명
coupangeats_sales_기간.csv엑셀에서 바로 여는 표 형식 (한글 안 깨짐)
coupangeats_raw_기간.json가공 전 원본 데이터 전체 (백업·분석용)

CSV 주요 항목: 주문일시 · 주문번호 · 상태 · 메뉴 · 주문금액 · 실지급액 · 판매가 · 할인액 · 취소금액 · 수수료합계 · 수수료VAT · 리뷰평점 · 요청사항

5. 매일 자동 실행 (선택)

정해진 시간에 자동으로 어제 매출을 저장하려면 Windows 작업 스케줄러에 등록하세요.

  1. 시작 메뉴에서 작업 스케줄러 실행 → 기본 작업 만들기
  2. 트리거: 매일, 원하는 시간 (예: 오전 9시)
  3. 동작: 프로그램 시작 → 프로그램에 run_daily.bat 경로 지정
  4. 완료. 창 없이 조용히 실행되어 output 폴더에 저장됩니다.
먼저 "2. 최초 준비"의 로그인을 반드시 끝내둬야 자동 실행이 정상 동작합니다.

6. 문제 해결

증상해결
CSV가 안 생기고 status=403 표시 저장된 로그인 세션이 만료된 것입니다. 쿠팡이츠_매출추출.bat을 다시 실행해 크롬 창에서 재로그인하면 됩니다.
기간 선택 창이 안 뜸 명령창을 닫고 쿠팡이츠_매출추출.bat을 다시 더블클릭하세요.
"Node.js가 설치되어 있지 않습니다" nodejs.org에서 Node.js 설치 후 다시 실행하세요.
다른 기간을 뽑고 싶음 기간 선택 창의 달력에서 시작일·종료일을 원하는 대로 지정하면 됩니다.
